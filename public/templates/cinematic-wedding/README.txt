CINEMATIC WEDDING WEBSITE — QUICK START

Files:
- index.html: website structure and 16 chapters
- styles.css: responsive visual design and 3D invitation styling
- script.js: invitation opening, navigation, animations, countdown, gallery lightbox and RSVP demo

Run:
1. Keep all three files in the same folder.
2. Open index.html in a modern browser, or use VS Code Live Server.
3. Internet is required for Google Fonts, GSAP, Lenis and remote Unsplash sample photos.

IMPORTANT CUSTOMIZATION:
- Replace Ananya and Rishabh with the couple's names.
- Replace the sample wedding date (18 February 2027) in index.html and script.js.
- Replace event dates, times, family names and venue details in index.html.
- Replace the sample Unsplash image URLs with the couple's own optimized images.
- The RSVP form is currently a front-end demo. It does NOT save submissions. Connect your API/backend in script.js before using it for real guests.
- The countdown is set to 18 February 2027 at 4:00 PM in the visitor's local browser timezone. Update the date/time in script.js.

The design is inspired by cinematic editorial/chapter-based storytelling, not a pixel-for-pixel copy of the reference site.
